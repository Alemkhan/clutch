# Контент Clutch

Все вопросы и наборы лежат здесь, по темам. Код читает эти файлы сам.

```text
questions/<тема>.json   вопросы с одним ответом (выбор из 4 или ввод)
sets/<тема>.json        наборы «назови …» (вопрос «что из этого — …?» и замороженный Last Stand)
```

Темы: science, space, nature, body, history, literature, art, music, film, popculture,
sport, food, math, language, tech, world.

## Статус

`editorialStatus` в каждой записи:

- `pending` — добавлено, в игре не появится;
- `approved` — в игре;
- `blocked` — убрано из игры, запись остаётся для истории.

Не удаляй записи, которые уже были в игре: ставь `blocked`.

## Добавить

```bash
npm run content:import -- путь/к/ответу_notebooklm.json
```

Файл может быть прямо скопированным ответом NotebookLM, даже с ```json и текстом вокруг.
Новые записи получают id и статус `pending`; дубли по тексту вопроса пропускаются.
`--approve` сразу ставит `approved`.

Вопросы из Wikidata: `npm run content:wikidata` (дописывает только новые).

## Проверить вопросы дня

```bash
npm run content:day -- 2026-10-18
```

Пишет в `content/review/` (не в git) все вопросы этого игрового дня с ответами, неверными
вариантами и `id`. Удобно вычитать то, что попадёт в кадр или в релиз.

## Править

Меняй текст, ответы и статус прямо в JSON. `id` не трогай: по нему игра связывает
вопрос со статистикой и старыми матчами.

## Проверить

```bash
npm run content:check
```

Ловит битый JSON, пустые поля, неверный вариант, который засчитался бы при вводе,
и наборы, где одно написание подходит двум ответам. Сообщение об ошибке называет файл
и номер записи. Запускай после каждой правки.

## Поля вопроса

`promptRu` вопрос · `answerRu` ответ, который увидит игрок · `acceptedRu` что засчитывать
при вводе · `acceptedEn` английские алиасы, если ответ известен и по-английски ·
`distractorsRu` ровно 3 неверных варианта · `openAnswer` можно ли вводом ·
`difficulty` Easy / Medium / Hard / Expert · `sourceTitle`/`sourceUrl` источник ·
`reviewNote` сомнения.

## Поля набора

`titleRu` «Назови …» · `mcPromptRu` «Что из этого — …?» · `members` все верные ответы
(от очевидных к редким; у каждого `id`, `answerRu`, `acceptedRu`) · `nonMembersRu`
не меньше 3 правдоподобных неверных.

Вопросы «На глазок» лежат не здесь, а в `docs/content/` (пак `tiebreaker-pack-v2.json` и разбор).
Статус одобрения всего пакета и риски по происхождению — [CONTENT_REVIEW](../docs/CONTENT_REVIEW.md).
