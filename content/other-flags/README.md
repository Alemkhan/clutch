# Pending-инвентарь «Других флагов»

`pending.json` генерируется командой `npm run content:other-flags` из Wikidata
и Wikimedia Commons. Он одновременно служит проверяемым источником runtime-набора:
`historicFlags.ts` берёт только одобренные владельцем свободные символы городов и штатов.
Знаки организаций, записи с ручной проверкой прав и `blocked` в игру не попадают.

Каждая запись сохраняет страницу Commons, автора, лицензию и URL сущности Wikidata. Год
принятия намеренно остаётся `null`, пока редактор не сверит его по первичному источнику;
в интерфейсе будущей игры подтверждённый год показывается как `Название · 2022`.

Для организаций нужен отдельный `trademarkReview`, даже если файл на Commons имеет свободную
лицензию. Они генерируются сразу как `blocked`: допустимо одобрить их только после проверки
официального флага и знака. Логотипы частных компаний в набор не входят.

`pending` означает, что media provenance собран, но не хватает первичного источника самого
символа и года. Его нельзя автоматически считать разрешением на публикацию: в runtime он
может попасть только после явного решения владельца. `approved_ready` не выставляется
генератором. Конфликтующие версии одного
городского герба/флага также остаются `blocked`, чтобы у игрока не возникли одинаковые варианты
ответа.
