## Открыто: в коде есть, ждёт проверки

- **R20 (частично).** Лимит 15 секунд на вопрос сервером не применяется. Нужен набор по
  одному вопросу — цена: предзагрузка картинок и возобновление забега. **Решает владелец**,
  не код.
- **R22/R23 на телефоне.** Звук (ogg-only), доставка уведомлений (включая диагностику
  `reasonCode` по логам), панель «Сообщить о проблеме» поверх клавиатуры, EN-алиасы по
  фактическому вводу латиницей.
- **R24–R26 на телефоне.** «На глазок» (ввод, клавиатура, шаринг в Mini App), экраны v2,
  известие «выбили из десятки», реванш из «Партий».
- **Cron возврата приглашений**, реванш и «Позвать друга» через настоящие Telegram-ссылки —
  не проверялись в реальном окружении.
- **Баг двойного тапа.** Диагностика `answer_option_mismatch` / `answer_replay_conflict`
  включена; ждёт повторения на телефоне, потом разбор по `analytics_events`.
- **Новый замер на людях** после перехода на соло и жёсткий молоток; затем
  `npm run calibrate:pricing` и решение по `setPar` ([CONTEXT](../CONTEXT.md), пробел 4).

## Открыто: следующее

- **R11 (хвосты).**
  - Контент: `lk/za/sz/nr/id` и чувствительные `xk/ps/tw/il` ждут решения владельца;
    «Другие флаги» и «Языки» без source/provenance; 271 авторская запись «Общих знаний»
    без источника. Снимать плохие записи статусом `blocked`, вычитывать темами по жалобам
    (начиная с NotebookLM). См. [CONTENT_REVIEW](CONTENT_REVIEW.md).
  - Наборы Last Stand слишком малы (≥7 участников у 13 из 52) — актуально только при
    разморозке режима.
  - Удалённый CI на GitHub не подтверждён.
- **R24d — новый пак «На глазок»: отложено.** Пак закончится 2026-10-25, дальше карточка
  скрыта. Владелец (2026-10-16): новый пак пока неинтересен. Правила контента — в
  [docs/content/tiebreaker-questions.v2.draft.md](content/tiebreaker-questions.v2.draft.md);
  загрузка — `npm run tiebreaker:load <json> [out.sql]` (печатает SQL, применять
  `wrangler d1 execute --local --file`). Калькулятор и блокнот на экране ответа — после
  первого замера.
- **«Дуэль за место»** — идея для недельной таблицы/лиг, не делать сейчас. Набросок: вызов
  только на стоящего выше с равными кругами; оба играют свежий набор; у защитника сутки,
  неявка — место остаётся за ним; не больше одного вызова на защитника в сутки. Таблица дня
  живёт до полуночи, защищаться пришлось бы ночью — поэтому для недельной.
- **Недельная таблица, лиги, таблица среди друзей** — когда будет больше игроков.
- **Палитра v6** — не выбрана владельцем; до выбора цвета и шрифты не менять.
- **Release-неполнота.** Сгенерированный preflight-config задаёт в `vars` только `ENVIRONMENT`;
  `TELEGRAM_MINI_APP_LINK`, `PUBLIC_WEB_ORIGIN` и web-переменную `VITE_TELEGRAM_BOT_LINK` пока
  добавляют вручную ([RELEASE](RELEASE.md)). Учесть при подготовке деплоя.
- **`skills-lock.json`** (неотслеживаемый, из установки skills) — решить: коммитить или
  добавить в `.gitignore`.
