# Аудит: открытые находки

Сверено 2026-10-22. Здесь только то, что остаётся открытым. Закрытые находки (A01–A04,
A12 и закрытые части остальных) с доказательствами — в
[archive/AUDIT_CLOSED.md](archive/AUDIT_CLOSED.md); нумерация сохранена. Находки выведены
из кода и живых замеров, это не пентест, не полная проверка контента и не прогон на
физических устройствах.

Приоритеты: **P0** — до публичного приёма результатов; **P1** — до закрытой беты/релиза;
**P2** — после устойчивого основного цикла. Открытых P0 нет.

## A05 · P1 · Условия skill-попытки не проверены на телефоне

Код исправлен: маркер молотка считает положение по активному elapsed time (треугольная
волна, кадр ограничен 50 мс, пауза при hidden), пороги зон едины для отрисовки, клиента и
сервера, таймер вопроса идёт от абсолютного deadline с one-shot gate ответа/таймаута,
pressure выводится из предыдущих non-miss результатов. Открыто: ручная проверка в Telegram
на телефоне (смещённые зоны, маленький экран, reduced motion, background/resume, экранная
клавиатура). При переработке анимации сохранять однократное завершение удара, включая
reduced motion и размонтирование.

Живая обратная связь 2026-10-22 выявила два эффекта; исправления есть в рабочем дереве,
открыта проверка на настоящих iOS и Android внутри Telegram:

- **Задержка касания:** обе игры фиксировали удар через поздний мобильный `click`, поэтому
  после физического касания маркер продолжал двигаться. Теперь первичный `pointerdown`
  немедленно фиксирует активное время и видимую позицию, останавливает rAF, а последующий
  `click` становится no-op; `click` сохранён как fallback для assistive activation.
- **Симметрия башни:** линейная геометрия отрисовки симметрична, но двоичная погрешность могла
  дать зеркальным дистанциям ровно на границе разные тиры (`0.28` и
  `0.28000000000000014`). Сравнение inclusive-порогов получило допуск `1e-12`; отклонение
  `1e-9` по-прежнему переходит в следующий тир, то есть видимые зоны и баланс не расширены.

## A06 · P1 · Остаточное доверие клиенту (утечка ответов закрыта)

Закрыто: вопрос уходит как `PublicQuestion` без ответа и пояснения; круг, оценку удара
(`active_elapsed_ms`) и окно ответа (`answer_window_ms`) считает сервер; режим гонки,
отдававший набор с ответами, удалён. Закреплено `tests/noAnswerLeak.test.ts` и HTTP-smoke.
Открыто:

- **Лимит 15 секунд сервер не применяет и нынешним протоколом применить не может:** набор
  уходит клиенту целиком, вопрос можно прочитать заранее, любой серверный дедлайн
  обходится выбором момента «начала». Нужен набор по одному вопросу — решение с ценой
  (предзагрузка картинок, возобновление забега). Решать владельцу.
- **Подобранный момент удара не исключён:** маркер периодичен (удачная фаза каждые
  1,2–3,3 с), знающий формулу вычислит нужное `activeElapsedMs`. Проверка окна отсекает
  невозможное время, а не подобранное. Для лиг следующий рубеж — поиск выбросов по
  `solo_run_rounds.active_elapsed_ms`, не криптография.
- **`responseTimeMs` — заявление клиента;** окно сервера — только верхняя граница
  (внутрь входят разбор, удар предыдущего круга, а у продолженного забега — время
  закрытой вкладки).
- **Принятое свойство, не дефект:** в 20 вопросах набора видно около шести десятков
  названий среди вариантов, и верный ответ открытого вопроса встречается неверным
  вариантом соседнего. Открытый вопрос от этого легче, но ответом не является.

Нужен явно выбранный уровень защиты (DEC-03 в [PRODUCT](PRODUCT.md)); это не повод строить
live PvP.

## A07 · P1/P2 · Публичный рейтинг не утверждён; сравнимость наборов не доказана

Разнообразие наборов закрыто дневным банком (12 наборов для «Общих знаний» и географии, по
6 для «Других флагов» и «Языков») и подбором в `solo/matchmaking.ts`. Открыто: сравнимость
`solo_score` — пар набора занижен на 12–22% (замер молотка до сужения зон), `setPar`
оценивает вопрос по формату, а не по трудности записи, между категориями счёт несравним.
Внутри одного набора порядок честен. Чинить только после нового замера
(`npm run calibrate:pricing`, пока данных мало). Решение DEC-03 (casual или соревнование
с рейтингом) не принято.

## A08 · P1 · Контент требует редакторской проверки

Автоматический `status: approved` генераторов — технический флаг, не проверка человеком:
у 197 стран, 44 флагов и 37 языков нет построчных источников. Пакет «Общих знаний» (657
записей) одобрен владельцем целиком без вычитки: у 271 авторской записи есть только
подсказка, где проверять; записи NotebookLM — самый рискованный слой. Механика закрыта
кодом: `acceptedEn` у 445 из 595 open-записей (остальные 150 — в allowlist теста), коллизия
«дистрактор засчитывается как ответ» — ошибка тестов, близкие пары (Левенштейн ≤ 1)
зафиксированы snapshot-эталоном, есть «Сообщить о проблеме». Открыто: спорные формулировки
(Моне/Мане, БЭСМ/МЭСМ — легитимные, но опасные дистракторы), вычитка источников,
неоднозначные столицы и чувствительные территории, provenance для «Других флагов» и
«Языков». Детали и список блокеров — [CONTENT_REVIEW](CONTENT_REVIEW.md).

## A09 · P1 · Мобильная и визуальная готовность не подтверждены

Исправлено в коде: таймер media-вопроса стартует после `load`, `lang=ru` и pinch zoom,
клавиатурная доступность разбора и молотка, роли progressbar/status/alert, один React-root
с loading shell, ограниченный Telegram bootstrap, системный Back по экранам, динамическая
высота viewport, прокрутка открытого ввода при клавиатуре. Всё покрыто автотестами и
браузерной эмуляцией 360/390 px. **Не проверено на телефоне:** Telegram Android/iOS,
экранная клавиатура, safe areas, длинные тексты, background/return, screen reader, pinch
zoom, плохая сеть, новые экраны v2. Визуал утверждён как MVP, палитра v6 не выбрана
([ART_DIRECTION](ART_DIRECTION.md), [BRIEF](design/v2/BRIEF.md)).

## A11 · P1 перед релизом · Не закончен контур эксплуатации

- **Deploy не выполнялся:** production D1, Worker, Pages, BotFather, секреты, remote-схема
  — не созданы и не проверены; GitHub Actions на remote не подтверждён. Чек-лист —
  [RELEASE](RELEASE.md). Это наблюдение по репозиторию, не доказательство отсутствия
  удалённого деплоя.
- **Уведомления:** adapter классифицирует отказ ограниченным `reasonCode` + `httpStatus`
  (тело ответа Telegram наружу не выносится), `notifications/*` пишут структурные логи с
  correlation id. Живая доставка (результат записи, реванш, «выбили из десятки») не
  проверялась; три адресных реванша ранее получили `failed` без причины.
- **Звук:** есть только `.ogg`; unlock по первому жесту, выбор источника по `canPlayType`,
  диагностика отказов и событие `sound_failure` — в коде, на телефонах не проверено.
- **Наблюдаемость:** сервер принимает события по allowlist (`POST /api/events`:
  `solo_run_started`, `solo_run_completed`, `training_started`, `sound_failure`,
  `tiebreaker_answered`, `tiebreaker_shared`, `answer_option_mismatch`,
  `answer_replay_conflict`) и репорты (`POST /api/reports`); клиентская
  `platform/analytics.ts` — очередь в памяти. Нет политики хранения, дашборда и корреляции
  analytics-id с id забега по всем событиям. Смотреть локально: `npm run reports`,
  `npm run activity`, `npm run player`.
- **Ассеты:** общие credits в README, но нет пофайлового manifest происхождения и лицензий;
  контуры стран (mapsicon) требуют указания автора и запрещают перепродажу — проверить
  совместимость до коммерческого трафика ([CONTENT_REVIEW](CONTENT_REVIEW.md)).
- Автоматического браузерного end-to-end и on-device QA нет.

## A13 · Данные: результаты до `6a060a1` недостоверны

До коммита `6a060a1` при `prefers-reduced-motion` клиент ставил маркер на цель, и каждый
удар давал 25 из 25 (100% за четыре круга). Сейчас положение маркера выводится из времени
и скорости; закреплено тестом. Записи, пережившие этот переход, нельзя считать честным
пулом и показывать в таблице (локальная база очищалась). Актуально при первом
наполнении remote из чужих данных.

## A14 · P1 · «Вики-путь» недостаточно объяснён новому игроку

По живой обратной связи 2026-10-22 обычному пользователю без контекста непонятны правила
«Вики-пути». В рабочем дереве перед стартом и продолжением добавлена короткая подсказка:
дана начальная статья и цель, переходить можно только по ссылкам внутри текущей статьи,
меньше переходов — лучше, попытка дня одна и её можно продолжить. Открыто: проверить текст
на человеке, который раньше режим не видел, и на экране 360 px с длинными названиями.
