# «На глазок»: черновик вопросов-прикидок

Статус: **черновик для отбора, не для продакшн-заливки.** Владелец сверяет каждое
число и источник перед попаданием в `tiebreaker_questions`; `source_url` и
`as_of_date` обязательны. Создан 2026-10-15 по итогам сессии дизайна (R24 в
[ROADMAP](../ROADMAP.md)).

## Правила отбора

1. Ответ — число; скоринг множителем `× = max(дуга/ответ, ответ/дугу)`, ниже — лучше.
2. Вопрос требует **декомпозиции** (прикидывается цепочкой), а не знания факта.
   **Уточнено владельцем 2026-10-15:** общеизвестные факты (высота Эвереста,
   население Земли, длина Нила) не годятся вовсе — их не разложить и к ним не
   дать подсказку. Образец — fermi.gg: составной вопрос («сколько деталей LEGO
   2×4 нужно, чтобы пересобрать Сфинкса»), разбор по шагам и источник на
   каждый шаг. Ниже большая часть пака этому не отвечает и подлежит замене
   (см. R24d в ROADMAP).
3. Число меняется во времени → фиксируется в тексте («на 2024 год, по данным ООН»).
4. **Исключена статистика по РФ и россиянам** — политически спорное (решение
   владельца 2026-10-15). Нейтральная инфраструктура типа метро — допустима.
5. Комьюнити-подачи на MVP нет.
