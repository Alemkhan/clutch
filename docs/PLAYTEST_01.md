# Отчёт #1 — первый живой тест на людях

Снят 2026-10-09 перед очисткой локальной D1. Данные собраны за период
**2026-09-12 — 2026-10-08**, основная масса — вечер 7 и день 8 октября, когда
ссылку на мини-апп раздали друзьям.

Это слепок локальной базы разработки, а не production-аналитика. Числа ниже —
то, что было в `match_runs` и `last_stand_runs` на момент снятия.

## Охват

| | |
| --- | ---: |
| Прохождений матча | 86 |
| Из них завершено | 65 |
| Разных игроков | 21 |
| Забегов Last Stand | 8 |

Среди игроков двое служебных (`ProbeA`, `ProbeB`) — мои проверочные запуски.

**Важная оговорка.** Правила менялись прямо посреди набора данных: в базе
соседствуют записи с пустой версией, `race-to-100-v1` и `race-to-100-v2`. За
эти же сутки сменились подбор набора вопросов, состав пула соперников и профили
ботов. Поэтому агрегаты ниже описывают **смесь режимов**, а не один
установившийся. Сравнивать их с будущими замерами напрямую нельзя.

## Матч: что показали люди

### Знание

| Категория | Матчей | Верных ответов | Медиана прогресса |
| --- | ---: | ---: | ---: |
| geography | 33 | 110/207 = 53% | 75% |
| history | 9 | 33/62 = 53% | 75% |
| languages | 23 | 77/120 = 64% | 61% |

### Навык почти ничего не решает

Распределение 220 попыток удара после верного ответа:

| Результат | Доля |
| --- | ---: |
| perfect (25) | 60% |
| great (18) | 33% |
| good (12) | 4% |
| weak (5) | 1% |
| **miss (0)** | **2%** |

**93% попыток дают 18–25 очков.** Мини-игра не различает игроков: кто ответил
верно, тот почти гарантированно получает близкий к максимуму прогресс. Тезис
«Knowledge earns the attempt. Skill wins the game» в данных не подтверждается —
исход определяет знание.

### Исходы и длина

- Победы **13 (20%)**, поражения **44 (68%)**, ничьи 6.
- Раундов за матч: `4р×18 5р×9 6р×13 7р×6 8р×19`, **медиана 6 из 10**.
- Полный набор из 10 вопросов не доигран **ни разу**.
- Длительность: медиана **49 секунд**, минимум 17, максимум 142.

Матч почти всегда обрывался досрочно, потому что соперник добирал до 100%.

### Пул соперников состоял из одних победителей

- Записей с `ghost_eligible = 1`: **19**, и у **всех прогресс ровно 100%**.
- Матчей против записи игрока 44, против бота 42.

Правило пригодности пускало в пул только тех, кто сам дошёл до 100%, а полный
набор не доигрывался никогда. В результате каждый новый игрок получал
безупречного соперника.

### Вопросы ходили по кругу

- Уникальных наборов вопросов: **35 на 86 прохождений**.
- Один набор был выдан **20 раз**.

Набор наследовался от соперника, поэтому расходился по цепочке игроков. При
повторе того же набора доля верных ответов росла примерно на **33 процентных
пункта** — люди запоминали ответы, а не отвечали по знанию.

### Сложность форматов

| Формат | Верных | Доля |
| --- | ---: | ---: |
| выбор + текст | 105/158 | 66% |
| выбор + флаг | 77/135 | 57% |
| открытый + флаг | 13/24 | 54% |
| открытый + текст | 9/19 | 47% |
| выбор + контур | 16/37 | 43% |
| **открытый + контур** | **0/16** | **0%** |

Назвать страну по силуэту вводом **не смог никто ни разу**. Узнавание выбором
даётся заметно легче припоминания вводом — готовая лестница сложности, если
понадобится.

### Вовлечённость

Медиана 4 матча на игрока, максимум 19. Топ активных:

| Игрок | Матчей | Завершил | Лучший | Категорий |
| --- | ---: | ---: | ---: | ---: |
| Алем | 19 | 14 | 100% | 1 |
| Fifteen The Goat | 9 | 8 | 100% | 3 |
| Alima | 9 | 5 | 97% | 3 |
| Colt | 7 | 6 | 100% | 3 |
| Rakhat Toleu | 7 | 7 | 100% | 3 |

Восемь игроков попробовали больше одной категории. Люди играли по многу раз
подряд — это аргумент против дневного лимита попыток.

## Last Stand: 8 забегов, режим только родился

Завершённых забегов два, оба **по таймауту**, медиана 6 кругов. Столкновений в
живых забегах — **ноль**: правило тогда считало занятым только названное строго
раньше игрока, а боты и записи отвечают на 8–11 секунде. Человек почти всегда
быстрее, поэтому механика не срабатывала.

Показателен один забег: ответы `cn, cn, us, ve, kz, cn` — Китай назван трижды,
и это законно, потому что повторы между кругами разрешены.

После снятия привязки ко времени столкновения начали срабатывать, но замеров на
людях по новой версии ещё нет.

## Что изменено по итогам

| Находка | Что сделано |
| --- | --- |
| Вопросы ходили по кругу | Дневной банк из 12 детерминированных наборов, наследование набора убрано |
| Повторная выдача того же соперника | Удалён fallback-запрос, игнорировавший уже сыгранных |
| Пул из одних стопроцентников | В пул пускаются записи от 3 раундов, прогресс оборвавшейся замирает |
| Один бот всегда одинаков | Четыре профиля разной силы со смещением к слабым |
| Две фактические ошибки в контенте | `bo` → Сукре, `gq` → Сьюдад-де-ла-Пас, с источниками |
| Столкновения не срабатывали | Снята привязка ко времени ответа |
| Два одинаковых круга подряд | Планировщик не ставит одну категорию в соседние круги |

## Что остаётся нерешённым

1. **Навык не различает игроков** — 93% попыток дают 18–25. Баланс не трогался.
2. **`invalid` в Last Stand бесплатен** — узкий круг перебирается вводом стран
   подряд до попадания.
3. **`atMs` присылает клиент** — граница доверия та же, что в матче.
4. **Ничего не проверено на физическом телефоне.**

## Почему базу чистим

Данные выше собраны на правилах, которых больше нет. Записи матчей несут
устаревшие `question_set_id` и версии условий, поэтому в новый пул соперников
они всё равно не попадают. Забеги Last Stand сняты до починки столкновений.
Держать их дальше — значит мерить будущие изменения о смесь трёх регламентов.

Следующий замер нужно снимать **после** прогона на телефоне и на одной
зафиксированной версии правил.
