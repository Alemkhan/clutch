# Карточки шаринга и аватарка бота

Исходники и пересборка изображений, которые уходят в превью ссылки при шаринге
результата и в профиль бота. Оформление — как в игре: тёмно-фиолетовый фон
(градиент `#2b2270 → #1f1850 → #160f3e`), фиолетовая шапка с логотипом,
объёмная жёлтая кнопка `#ffc94d` с нижней кромкой `#e39a26`, квадраты кругов
цветами зон мини-игры.

## Языки

Все ссылки шаринга несут параметр `l` (`ru` | `en` | `kk`, по умолчанию `ru`):
клиент ставит язык игрока (`apps/web/src/platform/share.ts`), Worker рисует на нём
карточку, страницу-превью и подготовленное сообщение (`apps/api/src/share/shareText.ts`).
Статичные картинки с текстом лежат в трёх вариантах: русский — исходное имя
(`win.png`, `og.png`), остальные — с суффиксом языка (`win.en.png`, `og.kk.png`).

## Файлы

| Исходник | Результат | Размер | Где используется |
| --- | --- | --- | --- |
| `win.html` | `apps/web/public/share/win.png`, `win.en.png`, `win.kk.png` | 1200×630 | запасная картинка `/api/share/card.png` при победе |
| `loss.html` | `apps/web/public/share/loss.png`, `loss.en.png`, `loss.kk.png` | 1200×630 | то же при поражении |
| `tie.html` | `apps/web/public/share/tie.png`, `tie.en.png`, `tie.kk.png` | 1200×630 | то же при ничьей |
| `avatar.html` | `apps/web/public/share/bot-avatar.png` | 512×512 | аватарка бота в BotFather (без текста, одна) |

Шаблоны общие: стиль в `card.css`, тексты по `?l=` — в `card.js` (совпадают с
`outcome` в `shareText.ts`). Открыть шаблон в браузере можно и напрямую
(`win.html?l=kk`), но тогда шрифт системный: Inter подкладывает только скрипт.

## Превью ссылок из игры

Ссылки «Поделиться», «Позвать друга» и «На глазок» ведут на страницы Worker
`/api/share/run` и `/api/share/guess`: у каждой своя карточка 1200×630 под
конкретный результат (`.png` рядом), после чего страница уводит в Mini App.
Карточки рисуются в `apps/api/src/share/runCard.ts` и `cardLayout.ts` (SVG → resvg),
общие детали оформления — в `cardKit.ts`, параметры и маршруты — в `previews.ts`.

Общая карточка игры `apps/web/public/og.png` (og:image сайта и запасная картинка,
если рендер упал) и её варианты `og.en.png`, `og.kk.png` собираются из того же SVG:

```bash
npx vite-node scripts/share-cards/render-og.ts
```

Кириллические подмножества Inter при загрузке переименовываются в «InteC»
(`renderCard.ts`), а текст карточек делится на кириллицу и латиницу: иначе resvg
рисует кириллицу в жирном заголовке начертанием 700, а цифры — 900. Казахские
буквы ә ғ қ ң ө ұ ү һ і есть в подмножестве cyrillic-ext.

## Пересборка

```bash
node scripts/share-cards/render.mjs
```

Скрипт рендерит HTML установленным Chrome или Edge (headless) с отдельным временным
профилем. Сеть не нужна: Inter берётся из `apps/api/src/share/interFonts.ts` и вместе
с копией шаблонов и `fonts.css` кладётся во временную папку. Правки цвета, размера и
текста делаются в `card.css`, `card.js` и HTML, затем скрипт запускается заново.

## Происхождение и права

Изображения сгенерированы в этом репозитории из собственной вёрстки, внешних
ассетов и сторонних изображений в них нет.

- Палитра взята из оформления игры (`apps/web/src/styles/tokens.css`).
- Шрифт — [Inter](https://fonts.google.com/specimen/Inter), SIL Open Font
  License 1.1, из `@fontsource/inter` (встроен в API для рендера карточек).
- Дата создания: 2026-10-08, новое оформление и языки: 2026-11-16.

Poppins в этих карточках намеренно не используется: в нём нет кириллицы.
