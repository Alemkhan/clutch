# Локальный промо-инструмент

`promo/` — отдельный локальный проект для записи и рендера роликов Clutch через Remotion.
Он намеренно не входит в корневой npm workspace, CI и production release: зависимости
устанавливаются отдельно командой `npm ci` из этой папки.

- `npm run capture` — записать исходные сцены из локально запущенного Clutch;
- `npm run studio` — открыть Remotion Studio;
- `npm run render` — собрать ролик и наложить синтезированный звук.

`node_modules/`, `capture/`, `out/`, `public/take-*.mp4` и синтезируемое аудио являются
локальными воспроизводимыми артефактами и не попадают в Git.
